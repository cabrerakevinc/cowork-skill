# cowork-skill

Marketplace repo for the `cowork` plugin (Cowork OS as a plugin). The plugin itself, with its own README, lives in [`cowork/`](cowork/).

## Install (Claude Code)

```
/plugin marketplace add cabrerakevinc/cowork-skill
/plugin install cowork@cowork-skill
```

## Install (Cowork desktop app)

Zip the `cowork/` folder contents as `cowork.plugin` and open it in the Claude desktop app, or ask the author for the file.

## Commands

`/cowork:bootstrap`, `/cowork:extend`, `/cowork:doctor`, `/cowork:end-session`. See [`cowork/README.md`](cowork/README.md).
