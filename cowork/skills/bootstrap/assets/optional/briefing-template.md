# Briefing template

The shape of any status update, research answer, or summary Claude produces for me. Every section optional except the first; never pad a short answer to fill the template.

1. **Direct answer** (1-3 sentences, the answer first)
2. **Key facts** (dated bullets, max 5)
3. **Details** (only the subtopics that matter)
4. **Recommendation / next step** (only if a decision is implied; one strong recommendation)
5. **Sources and dates**
6. **Caveats** (only if real)
